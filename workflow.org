#+title: emacs + hugo + ox-hugo workflow

- install hugo (extended version)
#+begin_src bash
  brew install hugo
#+end_src

- init site
#+begin_src bash
  cd docs
  hugo new site docs
#+end_src

- install theme (hugo-book)
#+begin_src bash
  git submodule add https://github.com/alex-shpak/hugo-book themes/hugo-book
#+end_src

- install ox-hugo
  See [[https://ox-hugo.scripter.co/#installation]]

- start hugo server
#+begin_src bash
  hugo server --buildDrafts --navigateToChanged
#+end_src
