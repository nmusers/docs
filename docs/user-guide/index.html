    User guide

    This is the official online user’s guide for NONMEM. It provides fundamentals of nonlinear mixed-effects model, basic model building using NONMEM, and NONMEM example models for population PK analysis.

    We recommend working through this guide, and refer to the NONMEM Reference Manual when necessary to clarify programming issues.
