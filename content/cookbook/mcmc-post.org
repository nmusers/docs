* Postprocessing MCMC draws
Each MCMC run generates posterior draws (samples) in .ext and .iph, as
described in [[file:/docs/reference-manual/files/#iph][output files]]. In this article we show how to postprocess
these draws in R.

Consider the following example. The model uses ITS to position the initial draws, followed by NUTS
sampler that draws.
#+INCLUDE: "/examples/nuts-post/w15.ctl" src perl

The raw output file contains the draws for THETA, OMEGA, and SIGMA:
#+INCLUDE: "/examples/nuts-post/w15_head_tail.ext" src r

Note that the ~delim=q~ option for ~$EST METHOD=NUTS~ effectively
saves .ext draws as a csv file and adds quotation to the column names.
The ~NITER=1000~ option requests 1000 draws. Their summary and
diagnostic information is printed on lines with dummy iteration id's "-100000000x".
# For example, the line with ITERATION "-100"

NONMEM provides a utility routine "format_draws.f90" to format the
the draw files for future csv parsing. So by building
and running the standalone tool on the .ext file
#+begin_src bash
  # compiles the fortran utility
  gfortran format_draws.f90 -o format_draws

  # save the output as csv
  ./format_draws w15.ext w15.ext.csv
#+end_src
one obtains a new ~w15.ext.csv~ file with the original draw but
title and summary lines commented out:
#+INCLUDE: "/examples/nuts-post/w15_head_tail.ext.csv" src r
Then we can read this file in R:
#+begin_src r
  data <- read.csv("w15.ext.csv", comment.char="#")
#+end_src

Alternatively, one can read the original .ext file and skip the title
and summary lines:
#+begin_src r
  data <- read.csv(text = head(readLines("w15.ext"), -6), skip=1)
#+end_src
Note that the "-6" argument here is ad hoc, in that the [[file:/docs/reference-manual/files/#raw-output][raw output
files]] may contain a different number of summary and diagnostic lines.
Alternatively one can simply remove the
lines with ~ITERATION<=-1000000000~.

Now we can do postprocessing through the R package [[https://mc-stan.org/posterior/index.html][posterior]]. We first
read in the ~data~ object as draws. We also skip the warmup (burn-in)
draws, the ones with ITERATION < 0 (the code shows ligatures so it may
not be the same as how it is typed, e.g. the R pipe "|>" is shown as
triangle ~|>~).
#+begin_src r
  library(posterior)
  d <- as_draws(data[data$ITERATION>=0, ])
  d$ITERATION <- NULL
#+end_src

Note that the file read converts subscript notation to
dots, e.g. "SIGMA(1,1)" to "SIGMA.1.1." and "PHI(1)" to "PHI.1.".
The standard deviation in the summary is exactly what is reported on
dummy ITERATION "-1000000001" in the original raw output. Details of
~rhat~, ~ess_bulk~, and ~ess_tail~ can be found [[https://mc-stan.org/rstan/reference/Rhat.html ][here]].

We can visulize the draws using the [[https://mc-stan.org/bayesplot/][bayesplot package]]. For example,
#+begin_src r
  library(bayesplot)

  mcmc_dens(d)
#+end_src
plots the posterior desity,
#+ATTR_HTML: :width 600
[[/docs/examples/nuts-post/dens.png]]

and
#+begin_src r
  mcmc_pairs(d, regex_pars="THETA*")
#+end_src
visulizes the correlation between THETAs (~regex_pars~ option selects
the parameters by regular expression, here all the THETA variables). We can see that the
clearance and the volume of distribution V1 & V2 are weakly correlated.
#+ATTR_HTML: :width 600
[[/docs/examples/nuts-post/theta_pairs.png]]

With option ~BAYES_PHI_STORE=1~, the individual draws are also output
in the .iph file. We can follow the same steps to read in those draws.
Note that .iph file does not contain the summary lines.
#+begin_src r
data_ind <- read.csv("w15.iph", skip=1)
d_ind <- as_draws(data_ind[data_ind$ITERATION>=0, ])
#+end_src
This draw object is much bigger than the population parameters, as it
contains the draws of PHIs and ETAs for each of the 100 subjects.

The posterior package provides many functions to manipulate draws. For
example, we can extract the individual parameters for subject 1, and
~bind_draws~ with the population parameter draws.
#+begin_src r
  d1 <- bind_draws(d_ind |> dplyr::filter(SUBJECT_NO==1) |> dplyr::select(-"MCMCOBJ"),
                   d |> dplyr::select(-"MCMCOBJ"),
                   along='variable')
#+end_src
The following pair plot shows that PHI and ETA are indeeded
correlated, and the residual error is likely not associated with them.
#+begin_src r
d1 |> mcmc_pairs(pars=c("PHI.1.","ETA.1.","SIGMA.1.1."))
#+end_src
