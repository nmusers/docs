* $INFN

Marks the beginning of abbreviated code for the INFN routine.

#+begin_src perl
 $INFN
 abbreviated code

;# example
 $INFN
 IF (ICALL.EQ.1) CALL SUPP (1,1)
#+end_src

** DISCUSSION
 The  $INFN  record is used to describe initialization processing for a
 NONMEM run, or NONMEM problem, or finalization processing for a NONMEM
 problem.  It is used with PREDPP.

 General   rules   for   abbreviated   code  are  documented  elsewhere
 (See @@html: <a href="/docs/reference-manual/abbr/">abbreviated code</a>@@).

(See @@html:<a href="/docs/user-guide/advanced/abbr_block/#initialization-finalization-block">Initialization-Finalization block</a>@@, Finalization example)

** RECORD ORDER

 Follows $SUBROUTINES.
