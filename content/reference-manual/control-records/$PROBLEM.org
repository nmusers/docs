* $PROBLEM
NONMEM Problem description.
#+begin_src perl
$PROBLEM  [string]
;# Example
$PROB  THEOPHYLLINE   POPULATION DATA
#+end_src

** Discussion
Every NONMEM model requires a ~$PROBLEM~ record as the start
a problem. The  ~string~ is a literal with maximum length 72 characters.
It will be in the heading of the printout.
When the problem is part of a superproblem,
~$PROBLEM~ is usually the first control record in a control stream,
unless preceded by a ~$SUPER~ record (as a subproblem), or by a ~$SIZES~
record.  A control stream can contain multiple
~$PROBLEM~  records, with each one marking the beginning of a problem specification.
