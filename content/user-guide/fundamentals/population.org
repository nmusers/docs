* Population models
In this chapter we discuss models for populations data. Those data
contain observations from a set of individuals sampled from a
population. Such data are characterized by one or more
observations for each individual. All the models
discussed here are /parameter models/, in that observations are described
with models with parameters. These models are capable of explaining the
data variability due to the those unknown random parameters.

** Problem formulation
:PROPERTIES:
:CUSTOM_ID: mixed_form
:END:
Individuals in a population of size \(N\) are different due to
/fixed/ and/or /random/ effects, manifested
as individual parameters \(\phi_i\), \((i=1,\dots,N)\), with
individual ID \(i\) in subscript. Then a general formulation for /mixed-effects/ model is to use certain
function \(f\) of known quantities
\(x_{ij}\) and unknown parameters \(\phi_i\) to describe the
observations \(y_{ij}\). This function \(f()\) is sometimes refered as
/structure model/. In reality \(f(x_{ij}, \phi_i)\) does not
account for all the variability of \(y_{ij}\), therefore we additively
complement it with a /residual error/ term \(\epsilon_{ij}\). In summary

$$
y_{ij} = f(x_{ij}, \phi_i) + g(x_{ij}, \phi_i)^T\epsilon_{ij}.
$$

Note
- Subscript \(ij\), \(j=1\dots,N_i\) denotes observation \(j\) for
  individual \(i\). Individuals often do not have same number of
  observations so in general \(N_i\ne N_k\) when \(i\ne k\).
  The total number of observations in a data set is \(N_{\text{obs}}=\sum_iN_i\).

- The term "nonlinear" in "nonlinear mixed-effects model" refers the
  fact that \(f()\) is often nonlinear with respect to \(x_{ij}\)
  and/or \(\phi_i\).

- NONMEM assumes that \(\epsilon_{ij}\) follows a multivariate normal
  distribution [fn:3],
  $$
  \epsilon_{ij} \sim \text{MultiNormal}(0, \Sigma).
  $$
  NONMEM uses reserved variable =SIGMA= for the covariance matrix
  \(\Sigma\). \(\epsilon_{ij}\) are assumed independent from \(\epsilon_{kl}\) when \((i,j)\ne (k, l)\).
  Function \(g()\) provides adjustment of \(\epsilon\), so that the
  residual error assumes variance \(g^T\Sigma g\). For example,
  + a \(1\times 1\) covariance matrix \(\Sigma\) with constant \(g()\equiv 1\) represents
    homoscedasticity in residual error. That is, all the observations
    \(y_{ij}\) share a same normally distributed residual error
    \(\epsilon\). This is sometimes referred as additive residual
    error model;

  + a \(1\times 1\) covariance matrix \(\Sigma\) with
    \(g(x_{ij},\phi_i)=f(x_{ij},\phi_i)\) represents proportional
    error model. It says the variance of the residual error is
    proportional to the squared prediction;

  + a \(2\times 2\) covariance matrix \(\Sigma\) with \(g(x_{ij},
    \phi_i)=[f(x_{ij}, \phi_i), 1]^T\) represents combined the additive
    and proportional residual error model. It is equivalent to
    $$
    y_{ij} = f(x_{ij}, \phi_i) + f(x_{ij}, \phi_i)\epsilon_{ij}^{(1)} + \epsilon_{ij}^{(2)},
    $$
    $$
    \epsilon_{ij}^{(1)} \sim \mathcal{N}(0, \upsilon_{11}),
    $$
    $$
    \epsilon_{ij}^{(2)} \sim \mathcal{N}(0, \upsilon_{22}),
    $$
    with \(\upsilon_{11}\) and  \(\upsilon_{22}\) the diagonal elements of
    \(\Sigma\);

  + a \(2\times 2\) covariance matrix \(\Sigma\) with
    \(g()^{(1)}\equiv g()^{(2)}\equiv 1\) represents multivariate
    residual error model (superscripts for types of observations):
    $$
    y_{ij}^{(1)} = f(x_{ij}, \phi_i)^{(1)} + \epsilon_{ij}^{(1)},
    $$
    $$
    y_{ij}^{(2)} = f(x_{ij}, \phi_i)^{(2)} + \epsilon_{ij}^{(2)},
    $$
    $$
    [\epsilon_{ij}^{(1)}, \epsilon_{ij}^{(2)}]^T \sim \text{MultiNormal}(0, \Sigma),
    $$
    One usse of this model is to describe concentration and effect
    data simultaneously.

  NONMEM provides control record [[/docs/user-guide/nmtran/control/#error][$ERROR]] to specify \(g(x_{ij}, \phi_i)\epsilon_{ij}\).

Next we describe the models for \(\phi_i\), by /assuming/ \(\phi_i\) deviates a
"typical" value by a random perturbation \(\eta_i\). By "typical" we mean
that the value is the same for individuals with same covariates
\(z_{i}\), e.g. weight and height. We
use function \(\mu()\) to describe this model: \(\bar{\phi}_i=\mu(z_i, \theta)\), with parameter
\(\theta\) and covariate \(z_i\) for "typical" value of \(\phi_i\), so that

$$
\phi_{i} = \mu(z_{i}, \theta) + \eta_{i}.
$$

Note
- We refer \(z_i\) as /fixed effects/, and \(\theta\) /fixed effect
  parameters/ [fn:1]. NONMEM uses reserved variable =THETA= for
  \(\theta\) [fn:2].
- We refer \(\eta_i\) as /random effects/. NONMEM uses reserved
  variable =ETA= for \(\eta\).
- A nonlinear \(\mu()\) contributes to additional nonliearity of the problem.
- In general for each individual, \(\theta\), \(\phi\), and \(\eta\) are vectors.
- NONMEM assumes all \(\eta_i\)'s follow a multivariate normal
  distribution [fn:3],
  $$
  \eta_i \sim \text{MultiNormal}(0, \Omega).
  $$
  NONMEM uses reserved variable =OMEGA= for the covariance matrix \(\Omega\).
- NONMEM output use =PHI= for \(\phi_i\)'s.
- In some of NONMEM's solution algorithms the above \(\mu() + \eta\) pattern can improve
  efficiency. See [[file:/docs/user-guide/techniques/mu_model][MU referencing]].

NONMEM refers the random effect with \(\phi\) (or equivalently \(\eta\)) as the
/first-level/, and the randomness due to \(\epsilon\) the
/second-level/. We can see that in general the variance-covariance structure for
residual error, \(g(x,\phi)^T\epsilon\), contains both levels of
random effects. In other words, \(\phi\) (or \(\eta\)) /interacts/
with \(\epsilon\) by contributing to the stochastic structure of the
residual error. This behavior is accounted for in NONMEM's estimation
methods through option "INTERACTION". By default the INTERACTION is
not activated. In that case, the residual error is estimated with
\(\eta=0\), becomes \(g(x, \phi|_{\eta=0})^T\epsilon\). We recommend
always use INTERACTION.

** Covariate models
In NONMEM guides the models for \(\mu()\) are called structure
parameter models. Here to avoid confusion with the model for \(f()\),
we use the term "covariate models", and discuss a few common
ones in PK applications. Assume \(\phi\)
has clearance CL as one of its elements,
then we use \(\tilde{\text{CL}_i}=\mu(z_i, \theta)\) for =TVCL= [fn:4], the "typical
value" of CL. In NONMEM the above equation for \(\phi\), i.e. the association of \(\theta\), \(\eta\), and
\(z\), are encoded in control record [[file:/docs/user-guide/nmtran/control/#guide_$pk][$PK]].

*** Linear (additive) models
The simplest form of \(\mu()\) is its being linearly related to
\(\theta\). For example, if CL is
the sum of renal and non-renal components (CL_{ren} and CL_{met}, respectively),
and CL_{ren} is
believed to be proportional to renal function (RF) as described according
to a standard formula involving covariates in \(z\): age (AGE),
serum creatinine (SECR), and weight (WT), then one might consider the
following model (we omit subscript \(i\) to avoid clutter).

$$
\tilde{\text{CL}}_{\text{met}} = \theta_1 \text{WT},
$$
$$
\text{RF}=\text{WT}\frac{1.66-0.011\text{AGE}}{\text{SECR}},
$$
$$
\tilde{\text{CL}}_{\text{ren}} = \theta_4 \text{RF},
$$
$$
\tilde{\text{CL}} = \tilde{\text{CL}}_{\text{ren}} + \tilde{\text{CL}}_{\text{met}}.
$$
Despite RF being a nonlinear function of covariates, the above model
shows a linear \(\mu\) with respect to \(\theta\), as (we use \(\cdot\) for inner product)
$$
\tilde{\text{CL}} = (\text{WT}, \text{RF}) \cdot (\theta_1, \theta_4).
$$
*** Multiplicative model
Multiplicative models are linear models on a logarithmic scale.
For example, if patients covering a very wide range of weights
are studied, metabolic clearance might vary with weight, but
not linearly. Then instead of modeling them linearly, we assume
$$
\log(\tilde{\text{CL}}_{\text{met}}) = \theta_1 + \theta_2\log(\text{WT}),
$$
equivalently [fn:5]
$$
\tilde{\text{CL}}_{\text{met}} = \theta_1\text{WT}^{\theta_2}.
$$
Note that the two sets of \(\theta\)'s are not the same, but since
they are unknown parameters we can transform them and fit either set
in a model. This /reparameterization/ is common in statistical modeling.
*** Saturation Models
A useful model for processes reaching a maximum is a hyperbolic model.
For example, if a second drug, (whose steady-state plasma
concentration, Cpss_2 is known and given in the data set), is present
in some individuals and it is believed to be an inhibitor of the
metabolism of the study drug, one might consider

$$
\tilde{\text{CL}}_{\text{met}}=\text{WT} \left(\theta_1-\frac{\theta_2 \text{Cpss}_2}{\theta_3 + \text{Cpss}_2}\right)
$$

The relationshiup is shown in figure below.  The inhibition is expressed by the
ratio occurring within the brackets and is a concave hyperbola,
asymptoting
to a maximum value equal to \(\theta_2\).  It is identical in form to
the Michaelis-Menten model.

*** Indicator variables
Assume a binary variable HF documents the clinical condition of heart
failure as "present" (HF=0) or "absent" (HF=1). To model heart failure
affected CL_{met}, we do [fn:5]
$$
\tilde{\text{CL}}_\text{met} = (\theta_1 - \theta_2\text{HF})\text{WT}.
$$

** Population random effects models
Under NONMEM nomenclature, there are two levels of random effects,
\(\eta\) and \(\epsilon\):

- \(\eta\) in the parameter model accounts for the /inter-individual/
  variability in \(\phi\) that is not explained by \(\mu(z_i, \theta)\);
- \(\epsilon\) accounts for the /intra-individual/ variability that is
  not explained by \(f(x_{ij}, \phi_i)\), thus formulates the error model.

The interindividual variability can arise from
- the approximate nature of \(\mu()\) to express the relation between
  covariates \(z\) and individual parameters \(\phi\);
- the covariates \(z\) contain measurement error.

The intraindividual variability can arise from
- the approximate nature of the structure model \(f()\);
- observed quantities \(x\) contain measurement error;
- the pharmacokinetic responses \(y\) contain measurement error (assay error).

*** Models for Interindividual variability
NONMEM uses \(\eta\) to describe interindividual variability.
Its covariance matrix \(\Omega\) is symmetric and
positive-semidefinite. NONMEM utilizes the symmetry so that only the
/lower triangular elements/ are used to specifiy =OMEGA=. For example,
in a two-compartment model we can have \(\eta=(\eta_{k10}, \eta_{k12},
\eta_{k21})\) for the elimination and transfer coefficients. Then
\(\Omega\) will be a 3x3 matrix but =OMEGA= contains only 6 elements:
(\(\text{cov}(\cdot,\cdot)\) indicates covariance).

$$
\omega_{11}=\text{cov}(\eta_{k10}, \eta_{k10});\\
\omega_{21}=\text{cov}(\eta_{k10}, \eta_{k12});\\
\omega_{31}=\text{cov}(\eta_{k10}, \eta_{k21});\\
\omega_{22}=\text{cov}(\eta_{k12}, \eta_{k12});\\
\omega_{23}=\text{cov}(\eta_{k12}, \eta_{k21});\\
\omega_{33}=\text{cov}(\eta_{k21}, \eta_{k21}).
$$

**** Additive model
An additive model, for example for volumn of distribution V:

$$
\text{V}=\tilde{\text{V}}+\eta
$$

leads to unit-dependent \(\omega\), as changing the unit of V will
cause \(\eta\) to change, so does its variance.

**** Multiplicative model
Also known as Constant Coefficient of Variation (CCV) model or
proportional error model, a multiplicative model such as
$$
\text{V}=\tilde{\text{V}}(1+\eta)
$$
does not change \(\omega\) when unit of V is alterered.

**** Exponential model
Exponential model is additive model on log scale.
$$
\log(\text{V}) = \log(\tilde{\text{V}}) + \eta\quad
\rightarrow\quad
\text{V} = \tilde{\text{V}}\exp(\eta).
$$
It does not change \(\omega\) when unit of V is alterered.

*** Generalized formulation
:PROPERTIES:
:CUSTOM_ID: general_mu_eta_form
:END:

Let us consider the following example. A study involves both patients in the intensive
care unit (ICU) and in the non-acute care units.  One could postulate
that ICU patients have higher variability in kinetics such as
metabolic clearance of drug due to unmeasured factors. For example,
their hepatic function could vary
greatly. Even though the variation
is actually due to a potentially measurable fixed effect
(hepatic function), when such information is not
available, \(\eta\) must account for the difference in variability in
the two grups.  One approach to do this is through indicator variable
ICU: ICU=1 for ICU patients and ICU=0 otherwise, and metabolic
clearance model [fn:6]

$$
\text{CL}_{\text{met}}= \tilde{\text{CL}}_{\text{met}} + (1-\text{ICU})\eta_1+\text{ICU}\eta_2,
$$

in addition to renal clearance model

$$
\text{CL}_{\text{ren}}= \tilde{\text{CL}}_{\text{ren}}(1 + \eta_3).
$$

Thus here \(\phi\) (corresponding to CL here), is associated to than
one \(\eta\)'s (\(\eta\)_{1-3} here), and not in the form of
\(\phi=\mu+\eta\). Another example where  [[#mixed_form][the additive form]]
for \(\eta\) is not applicable is when \(\phi\) is associated with
\(\eta\) nonlinearly.

Hence we want to generalize the parameter model, so that [fn:7]

$$
\phi_i=\mu(z_i, \theta, \eta_i),
$$
and we allow the dimention of \(\phi_i\) and \(\eta_i\) to be different.

** Population mixed effects model
In summary, the population mixed effects model in NONMEM has the
following general form.
$$
y_ij = f(x_{ij}, \phi_i) + g(x_{ij}, \phi)^T\epsilon_{ij},
$$
$$
\phi_i = \mu(z_{i}, \theta, \eta_i).
$$
In NONMEM we use "control records" to specify the above model: though
NONMEM provides control record $PRED to the entire model, more often
for pharmacometrics applications we use NONMEM's built-in models and
  - control record $SUBROUTINES to specifiy \(f()\);
  - when \(f()\) is based on numerical solutions of differential equation systems,
    we use $DES, $AES, and $MODEL to specify them;
  - $PK to specify \(\mu()\);
  - $ERROR to specify \(g()^T\epsilon\);
  - $THETA, $OMEGA, $SIGMA to specify the initial estimate and
    constraints of \(\theta\), \(\Omega\), and \(\Sigma\), respectively.
All the mentioned control records will be discussed in the next part
of the guide.

[fn:1] The nomenclature can be confusing in statistical literature, as
often \(\theta\) is also called the "fixed effects",
and the value of \(\theta\) "fixed effects size". In this document we
try to make the context clear whenever those terms are used.
[fn:2] Later on we will discuss situations when not all \(\theta\)'s are associated with \(\mu\) or \(\eta\) in this way.
[fn:3] In this document we use symbol \(\sim\) to indicate a distribution statement. This is common in statistical literature.
[fn:4] Prepending "TV" to a quantity name is a common practice, but note "TVCL" is not a reserved name in NONMEM.
[fn:5] Heart failure is expected to decrease metabolic clearance.  Thus using a minus sign here implies \(\theta_2\) is assumed positive.
[fn:6] To avoid clutter here we use subscript for  different \(\eta\)
for a same subject  instead of subject ID.
[fn:7] Here the subscript is for subject ID. We hope the context is
clear when we use the subscript differently.
